
# National Health Survey – Healthcare Dashboard | Power BI

## Dashboard Preview

![National Health Survey Dashboard](Dashboard_Screenshot.png)

## Problem Statement

Healthcare survey data contains information across different states, demographic groups, health schemes, and health indicators. Analyzing this data in raw form can make it difficult to identify patterns and compare important indicators.

The objective of this project is to build an interactive Power BI dashboard that transforms National Health Survey data into clear and meaningful visual insights.

## Project Objective

- Analyze healthcare and demographic data
- Compare state-wise indicators
- Analyze health scheme distribution
- Explore chronic disease indicators
- Analyze gender and marital status
- Present insights through interactive visualizations

## Dashboard Features

- Interactive KPI cards
- State-wise analysis
- Gender analysis
- Marital status analysis
- Health scheme analysis
- Chronic disease analysis
- General education analysis
- Interactive filters and charts

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization

## Key Insights

The dashboard provides an interactive view of healthcare and demographic data, allowing users to compare different states and categories and identify patterns across the available survey indicators.

## How to Use

1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data if required.
4. Use the available filters and visualizations to explore the dashboard.
